Cómo se encadenan las herramientas para producir un video faceless de punta a punta. Todas usan tu API key (Groq/Gemini, gratis) que ponés en Opciones. La voz usa el sintetizador del navegador (sin créditos).

🔁 El flujo recomendado

1) NicheMaster → validás el nicho (score, RPM, sub-nichos, ideas). 2) RivalRadar → espiás la competencia (búsquedas, formatos, huecos). 3) ScriptPilot → generás el guion + escenas + título/desc/tags. 4) VoxBatch → narrás el guion (voz del navegador) o exportás SSML. 5) MotionForge → prompts de imagen por escena + miniatura. 6) Command Center lands everything you save, scored and ranked.

📜 ScriptPilot AI

Tema + nicho + duración + idioma → guion continuo, breakdown por escenas, metadata lista para subir. Botones para mandar el guion a VoxBatch o MotionForge.

🎙️ VoxBatch Pro

Pegás el guion, lo divido en escenas y lo narro con voces del navegador (gratis). Elegís voz, velocidad y tono. Exportás la cola en SSML. La voz no se guarda como archivo desde acá: grabala o subí tu MP3 directo a Monetize Studio.

🎨 MotionForge Studio

Guion → un prompt de imagen/video por escena (en inglés, listo para Flow/Veo/Midjourney/Nano Banana) con estética coherente, + 3 conceptos de miniatura de alto CTR.

🛰️ RivalRadar Pro

Nicho/keyword → búsquedas que abren YouTube con un clic, formatos que funcionan, huecos sin explotar, ángulos de monetización, RPM y saturación.

📊 NicheMaster

Nicho → score de oportunidad (0-100), RPM, demanda, saturación, fit faceless, sub-nichos jugosos, ideas de video (clic → ScriptPilot), monetización y riesgos.

🔑 ¿No genera nada?

Necesitás una API key (gratis): Groq (console.groq.com) o Gemini (aistudio.google.com). Pegala en Opciones y volvé.
