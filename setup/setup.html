Setup

Pick one and the assistant starts working. You only need one, and you can change it later from the model picker in the chat. The local option and the two free tiers cost nothing.

Run a model on your own machine

checking

Nothing leaves your computer and there is no key and no quota. It needs Ollama, which is a free program.

Ollama is not answering on this machine. Install it, leave it running, and press check again.

curl -fsSL https://ollama.com/install.sh | sh

On macOS and Windows you can also download the installer from ollama.com. Once it runs, it listens on 127.0.0.1:11434.

Use a cloud key

no key yet

Faster than a local model. Groq and Gemini have a free tier, OpenAI is paid. The key is stored on this machine and is sent only to the provider you paste it for.

This one is not free, you pay per use. It is the quickest to set up if you already have a key, and GPT-4o mini answers in about a second. Get one at platform.openai.com/api-keys.

Get one at console.groq.com/keys. Sign in, create a key, copy it here. Groq is the fastest of the three.

Get one at aistudio.google.com/apikey. This is the only one that can read images, so the thumbnail features need it.

Local files for the offline features

optional

Face detection on thumbnails already works out of the box. Local transcription needs three model files that are not stored in the repository, because they are large. A page cannot write into the extension folder, so this one is a command.

./scripts/fetch-assets.sh

Run it inside the folder you loaded in chrome://extensions. Each file is checked against a known hash before it is kept.
